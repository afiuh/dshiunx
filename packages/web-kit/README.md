# web-kit

四区 + 并行区的万能 Web 框架。**只提供容器和交互，不规定内容语义。**

## 五区

| 区 | 位置 | 框架保证 | 应用放什么（不预设） |
|---|---|---|---|
| **D** | 顶部横条 | 全宽、高度可拖、可收起 | 分组 / 工具栏 / 标题 / 状态… |
| **C** | 左侧竖条 | 宽度可拖、可收起 | 列表 / 树 / 大纲 / 文件… |
| **A** | 主区 | 自适应、主内容 | 内容 / 设置 / 表单 / 编辑器…（**可自带操作**） |
| **B** | 底部横条 | 全宽、高度可拖、可收起 | 对话框 / 终端 / 输入 / 日志…（**可空**） |
| **E** | 右侧并行区 | **按需出现**（空则不渲染）、宽度可拖、面板可分割 | 任何需要并排的东西 |

## 关键语义

- **A 可以自带操作**：打开设置页 → 直接在 A 里操作，不需要 B。
- **B 不是「操作区」**：操作可以在 A 里；B 是「需要一块独立区域时」才用（对话框 / 终端 / 输入）。
- **E 是条件存在的**：`panels.length === 0` → 不渲染；拖条目到 A 右侧检测区 → 出现；关完 → 消失。
- **框架不管**：每个区放什么、操作谁、A/E 关系、数据从哪来。

## 契约

```tsx
<Workbench
  groups={groups}                    // D：分组
  itemsOf={group => items}           // C：条目
  renderContent={item => <.../>}     // A：内容
  renderActions={item => <.../>}     // B：独立交互区（可选）
  renderPanel={item => <.../>}       // E：并行面板（可选，默认同 A）
  theme="light" | "dark"             // 可选
/>
```

## 交互

| 操作 | 行为 |
|---|---|
| 拖边界 | 调尺寸（D 高 / C 宽 / B 高 / E 宽 / 面板占比） |
| 拖 C 条目 → A 右侧 | 检测区出现 → 松开 → **E 出现** |
| 拖条目 → E | **新增面板** |
| 关面板 × | 面板消失；空了 → **E 消失** |
| 点边界圆钮 | 收起/展开（展开时箭头指向区域内部，收起时指向外部） |

## 边界（框架不做的）

- 不规定内容语义（A 是设置还是对话，应用决定）
- 不规定 B 放什么（对话框 / 终端 / 空）
- 不规定 E 面板和 A 的关系（是否互换、是否共享选中）
- 暂不做：持久化、URL 状态、键盘导航、响应式、无障碍（后续）

## 结构

```
src/
├── types.ts                契约（Group / Item / Panel / WorkbenchProps）
├── hooks/
│   ├── useWorkbench.ts     数据状态（分组 / 条目 / 选中 / 并行）
│   ├── useResize.ts        尺寸 + 拖拽（起始值 + 增量）
│   └── useDropTarget.ts    拖放状态
├── workbench/
│   ├── Workbench.tsx       组装（五区 + E 条件渲染）
│   ├── Groups.tsx          D
│   ├── Index.tsx           C
│   ├── Content.tsx         A
│   ├── Actions.tsx         B
│   ├── Parallel.tsx        E
│   ├── Panel.tsx           F/G
│   ├── DropZone.tsx        检测区
│   ├── Grip.tsx            拖拽手柄
│   └── Arrow.tsx           收起箭头
└── styles/
    ├── theme.css           黑白变量
    ├── layout.css          五区布局
    └── components.css      组件样式
```
