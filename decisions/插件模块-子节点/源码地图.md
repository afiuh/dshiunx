## 6. 勘察结论（写决策时的注意事项）

1. **内核已覆盖的不重写**：loader / include / hmr / logger 的决策在内核模块，插件侧只写"如何使用"。
2. **`dsh-app-boot` 是隐藏大头**：5,372 行，profile 解析 1,072 行，启动链路必须拆 5 个文件。
3. **工具机制 > 具体工具**：`dsh-tools` 5,782 行（PTC + 调度 + schema），比任何单个工具都复杂，必须拆 4。
4. **`api-catalog.ts` 8,974 行是生成物**：决策只写"由 gen 脚本产出、内容为 API 目录"，不分析内容。
5. **catalog 分类靠正则**（`gen-catalog.mjs:15-21`）：这是"插件分类"决策的关键实现细节，分类维度不是人工标注。
6. **preset 是插件组**：`cordis:group` + `isolate` 构成 preset 子树，preset 注册表负责挂载与组合清单。
7. **插件演化已有完整实现**：安装/审批/注册表/回滚都在 `dsh-plugin-manager`；其中"版本豁免"与 `engines.dsh` 判定**违反 P7，属待剥离**（决策只写保留部分）。
