# 工作模块

**父模块**：`../root.md`

## 为什么存在

维叶莎"做事"的部分，按功能分三块：**想**（思考分析）、**做**（执行能力）、**记**（数据信息管理）。

## 输入 / 输出

- 输入：文本（语音/键盘）、当前上下文；
- 输出：执行结果、写入记录、任务状态。

## 边界

- 不执行长任务（交给 pi 对话）；
- 笔记写入任意，用户审核；
- 系统操作不二次确认，但要有记录；
- 不替用户做价值判断。

## 子节点

- `思考分析/node.md`（意图路由 / 任务识别 / 记忆检索）
- `执行能力/node.md`（任务分配 / 系统控制 / 能力清单）
- `数据信息管理/node.md`（笔记库读写 / 事务录入 / 记忆存储 / 审核追溯 / 环境）
- `技术选型/node.md`（dshiunx 插件组、语言边界）
