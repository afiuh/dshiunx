# 执行能力

**父模块**：`../node.md`

## 为什么存在

维叶莎"做"的部分：拉起 pi 对话（任务分配）、控制系统（应用/命令/窗口）、调用工具（能力清单）。

## 输入 / 输出

- 输入：任务/指令；
- 输出：执行结果、任务状态。

## 边界

- 不执行长任务（交给 pi 对话）；
- 系统操作不二次确认，但要有记录；
- 能力清单是"有什么工具"，不是"怎么用"。

## 子节点

- `任务分配/node.md`（拉起/继续 pi 对话 + 结果回传）
- `系统控制/node.md`（应用文件 / 命令 / 窗口媒体）
- `能力清单/node.md`（9 个 skill 的清单）
