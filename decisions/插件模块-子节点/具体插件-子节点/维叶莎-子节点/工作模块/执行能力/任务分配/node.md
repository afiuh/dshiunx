# 任务分配

**父模块**：`../node.md`

## 为什么存在

助手不执行长任务；需要把任务交给专门的 pi 对话。

## 输入 / 输出

- 输入：用户指令/任务；
- 输出：拉起/继续专门的 pi 对话。

## 边界

- 不执行长任务；
- 怎么分配，具体情况具体分析；
- 不自动替用户决定。

## 阶段 3 实现（2026-10-25）

- `src/skills/pi_task.py`：`pi -p` 新会话；`pi --session <id> -p` 指定会话；
- 路由：“任务：…” → 拉起 pi；
- 测试：“任务：用一句话回答 1+1” → “1+1 等于 2。”；
- 指定会话/结果回传/后台执行后续打磨。
