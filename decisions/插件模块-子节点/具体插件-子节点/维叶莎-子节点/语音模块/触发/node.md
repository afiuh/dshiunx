# 唤醒方式

**父模块**：`../node.md`

## 为什么存在

决定助手什么时候开始听；避免全天录音。

## 输入 / 输出

- 输入：按键/唤醒词；
- 输出：开始录音/触发 fcitx5-vinput。

## 边界

- P0 用按键（Alt+Z / Super+J），不做唤醒词；
- 不做全天录音；
- 后续可选 openWakeWord/sherpa-onnx KWS。

## 待确认

- P0 按键用哪个：Alt+Z（输入法）还是 Super+J（助手）；
- 不做唤醒词（方案 A：开关 + 按键/快捷键触发）。

## 验证

按键触发可靠；不误触；不常驻录音。
