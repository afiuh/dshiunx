# 对话展示

**父模块**：`../node.md`

## 为什么存在

用户要能看完整对话与结果，判断助手汇报是否正确；语音不够。

## 输入 / 输出

- 输入：消息、工具调用、执行结果；
- 输出：可滚动、可复制、结构化的展示。

## 边界

- 只读，不修改业务数据；
- 长内容可折叠/分段；
- 不阻塞输入。

## 信息清单（2026-10-25）

| 信息 | 展示 | 状态 |
|---|---|---|
| 用户消息 | 气泡（语音/键盘来源） | ✅ |
| 助手回复 | **流式**（`assistant-delta` 逐块）+ Markdown（marked，结束后渲染） | ✅ |
| 思考过程 | 折叠块（`<details>`） | ✅ |
| 工具调用 | 折叠卡片（`MessageItem` 内 `<details>`；名称/状态 running·done·error） | ✅ |
| 执行结果（notes/tasks/system/dispatch 摘要） | 结构化摘要 | ❌ 待做 |
| 错误 | 一行，不刷屏（SSE `error`） | ✅ |
| 公式（`\[ ... \]`） | KaTeX | ❌ 待做（marked 不渲染公式） |

## 验证

完整对话可回看；工具调用可展开；结果可复制。
