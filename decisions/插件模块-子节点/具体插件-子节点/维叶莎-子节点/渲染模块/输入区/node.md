# 输入区

**父模块**：`../node.md`

## 为什么存在

**语音是主输入**：说话 → ASR → 直接发送。键盘是辅助输入（打字/修正）。

## 输入 / 输出

- 输入：语音（主）、键盘（辅）；
- 输出：直接发送给 agent。

## 边界

- **语音是主输入**：ASR 结果直接发送，不强制确认；
- 键盘完整支持（多行、历史、快捷键）；
- **可选编辑**：识别错时可改（不是默认流程，不阻塞主路径）；
- 不打断当前输出。
