# 状态面板

**父模块**：`../node.md`

## 为什么存在

"统筹对话"需要看到多个会话/任务的状态，而不是只有一个当前对话。

## 输入 / 输出

- 输入：会话列表、任务状态、语音状态；
- 输出：侧栏/状态栏（运行中/等待/完成/失败）。

## 边界

- 只读；点击可进入对应会话（后续）；
- 不堆信息，只显示判断所需的。

## 信息清单（2026-10-25）

| 信息 | 来源 | 状态 |
|---|---|---|
| 连接状态 | SSE | ✅（connected / reconnecting） |
| 模型名 | 静态 | ✅（deepseek-flash，暂硬编码） |
| 品牌 | 静态 | ✅（dshiunx · 维叶莎） |
| 会话列表 | `ctx.sessions` | ❌ 占位（只有「当前对话」） |
| 任务状态 | dispatch + agent | ❌ 待做 |
| 语音状态 | `jarvis-voice` | ❌ 待做（按钮内有录音/识别态） |
| 写入/回滚点 | git commit | ❌ 待做 |

## 验证

能一眼看出哪些任务在跑、哪些完成、哪些失败。
