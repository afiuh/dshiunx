# web-kit（Web 前端母体）

**父级**：[具体插件](../具体插件.md)

> **同级插件**：不属于任何业务（维叶莎只是使用者之一）。

## 为什么存在

后面所有 Web 前端插件（维叶莎 / 未来的管理台、监控、编辑器…）都按同一套结构做：**D 分组 / C 索引 / A 内容 / B 区域操作 / E 并行**。没有母体，每个插件重写布局 + 拖拽 + 收起，必然分裂。

## 五区语义

| 区 | 框架保证 | 应用放什么（不预设） |
|---|---|---|
| **D** | 顶部横条，高度可拖，可收起 | 分组 / 工具栏 / 标题 / 状态 |
| **C** | 左侧竖条，宽度可拖，可收起 | 列表 / 树 / 大纲 / 文件 |
| **A** | 主区，自适应 | 内容 / 设置 / 表单 / 编辑器（可自带操作） |
| **B** | 底部横条，高度可拖，可收起 | **需要区域的操作**：对话框 / 终端 / 输入 / 命令（可空） |
| **E** | 右侧并行区，**按需出现**（空则不渲染），宽度可拖，面板可分割 | 任何需要并排的东西 |

## 框架边界

- **管**：五个位置、拖拽调尺寸、收起/展开、E 的按需出现/消失
- **不管**：每个区放什么、操作谁、A/E 关系、数据从哪来
- 只读的看（日志 / 输出 / 预览）**不放 B**：放 A 或 E

## 代码位置

- 包：`dshiunx/packages/web-kit/`
- 包名：`@dshiunx/web-kit`
- 形态：**React 组件库**（不是 Cordis 服务；其他 web 插件 `import { Workbench }`）
- 依赖：`react` / `react-dom`（peer）

## 与其他插件的关系

```
web-kit（母体，无业务）
  ← jarvis-web（维叶莎，已归档）
  ← 未来的管理台 / 监控 / 编辑器…
```

- `web-kit` 不依赖任何业务插件
- 业务插件依赖 `web-kit` 的组件，自己提供数据 + 渲染函数
