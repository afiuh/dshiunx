# 语音模块

**父模块**：`../root.md`

## 为什么存在

维叶莎的入口是"说话"：把语音变成文字（输入），把回复变成语音（输出），并决定什么时候开始听（触发）。

## 输入 / 输出

- 输入：麦克风 / 按键 / Shell 命令；
- 输出：文本（给工作模块）、语音（给用户）。

## 边界

- 不做全天录音；
- 不做本地 ASR（复用 wetype，在线、不占显存）；
- P0 不做唤醒词；
- TTS 默认 Edge-TTS 晓晓。

## 子节点

- `输入/node.md`（ASR：wetype 独立抽取）
- `输出/node.md`（TTS：Edge-TTS）
- `触发/node.md`（按键 / Shell 命令 / 快捷键）
