# TUI

**战略**：TUI 是插件，不是独立 app；先 TUI，后布局树；信息与渲染解耦。

## 讨论链

1. 功能都有了，接下来打磨使用体验。
2. 判断：TUI 必须放在插件体系内部（多插件信息整合），不能做成独立 app。
3. 收敛：TUI = Cordis 插件；参考 pi 的交互 + dsh-TUI 的投影设计；不弹审批。
