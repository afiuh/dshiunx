# 外围简化

**父战略**：[运行时能力](../README.md)

## 讨论链

1. 用户：“外围应该还有简化的空间吧”。
2. 判断：内核保留 Node，但 arch bundle、入口、数据目录可以砍。
3. 收敛：第一版只留 22 条 arch bundle，入口用 headless CLI。

## 决定（第一版）

1. arch bundle 只留 22 条
2. 入口换成 headless CLI，去掉 SDK JSON-RPC
3. 去掉 tsx，用 tsc 预编译
4. 依赖显式声明，不让 npm 自动装 peer
5. 数据目录简化为单一 `~/.local/share/dshiunx/`
6. 删遥测/账号（otel、credentials、deepseek-account）

## 中期

预编译/单文件 bundle、Node SEA、自编译 Node、系统集成、Rust/Go 外壳。
