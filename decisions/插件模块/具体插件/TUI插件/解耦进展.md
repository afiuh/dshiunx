# 解耦进展

**父级**：[TUI 插件](./TUI插件.md)

## 为什么需要

记录 TUI 从 `dsh-tui`（20 万行）解耦的进展。

## 准备怎么实现

### 宏观想法

从 `dsh-tui`（20 万行）拆出，**保留功能不保留结构**——记录进度，避免重复劳动。

```
dsh-tui → tui-protocol/chat/status → 剩余组件库
```

**为什么记录**：解耦是长期任务，进度要可追踪。
