# 会话

**父级**：[运行时基础](../运行时基础.md)

## 为什么需要

智能体的每次思考、每次工具调用、每次用户输入都要留下痕迹——否则无法恢复、无法投影、无法压缩。会话是这些痕迹的载体。

## 准备怎么实现

### 宏观想法

```
写入：事件（event）→ 持久化（jsonl）
读取：事件流 → 投影（projection）→ 消费者（界面/压缩/统计）
```

- **事件是唯一真源**：状态由事件推导，不单独存"当前状态"
- **投影是按需计算**：界面要什么就投影什么，投影可重建
- **持久化是追加**：jsonl 追加写，崩溃后能恢复到最后一个完整事件

### 边界

| 会话负责 | 不负责 |
|---|---|
| 事件的定义与追加 | 事件怎么产生（智能体/工具/用户） |
| 投影的注册与计算 | 投影怎么展示（界面） |
| 持久化与恢复 | 压缩策略（压缩是使用方） |
| 存储抽象（本地/远程） | 具体存储后端（子实现） |

### 验证

- 杀掉进程后重启，会话恢复到最后一个完整事件
- 投影可从事件流完整重建（删掉投影缓存不影响正确性）
- 新增一种投影不需要改会话核心
