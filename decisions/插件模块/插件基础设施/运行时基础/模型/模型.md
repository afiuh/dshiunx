# 模型

**父级**：[运行时基础](../运行时基础.md)

## 为什么需要

智能体本身不会说话——它通过模型适配器把"会话 + 工具定义 + 系统提示"变成一次请求，再把响应变回事件。

## 准备怎么实现

### 宏观想法

```
智能体 → llm 服务（路由）→ 适配器（provider）→ 外部 API
                                    ↓
                              计量（token）/ 重试 / 错误分类
```

- **路由按 provider + model**：适配器注册自己支持的 provider
- **适配器隔离协议差异**：上游 API 的形状只在适配器里
- **计量独立**：token 统计不进入请求路径，作为投影/旁路

### 边界

| 模型负责 | 不负责 |
|---|---|
| 请求/响应的协议转换 | 提示词内容（智能体） |
| 路由与回退 | 工具定义（工具插件） |
| 流式输出的组装 | 会话写入（智能体） |
| token 计量、重试、错误分类 | 成本策略（使用方） |

### 验证

- 换适配器（DeepSeek → 其他）不改智能体代码
- 流式响应中断时，已产出的内容不丢
- 计量可从事件流重建（不依赖内存计数）
