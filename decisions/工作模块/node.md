# 工作模块

**父模块**：`../root.md`

## 为什么存在

维叶莎"做事"的部分：读写笔记、录事务、分配任务（统筹对话）、控制系统、记住上下文、留痕可回滚。

## 输入 / 输出

- 输入：文本（来自语音模块/键盘）、当前上下文；
- 输出：执行结果、写入记录、任务状态。

## 边界

- 不执行长任务（交给专门的 pi 对话）；
- 笔记写入任意，用户审核；
- 系统操作不二次确认，但要有记录；
- 不替用户做价值判断。

## 子节点

- `笔记库读写/node.md`（检索 / 读取 / 写入）
- `事务录入/node.md`（结构化 / 写入 / 确认）
- `任务分配/node.md`（识别 / 拉起 pi / 结果回传）
- `系统控制/node.md`（应用文件 / 命令 / 窗口媒体）
- `长期记忆/node.md`（记什么 / 存哪 / 检索注入 / 更新遗忘）
- `审核追溯/node.md`（记录 / 审核 / 回滚）
