# 记忆存储

**父模块**：`../root.md`

## 为什么存在

跨会话记住用户、项目、笔记、事务、对话历史；否则每次都要重新交代背景。

## 输入 / 输出

- 输入：对话、笔记、事务、项目状态；
- 输出：跨会话检索/更新。

## 边界

- 记什么、存哪、怎么检索/更新/遗忘，由本节点子节点决定；
- 不替代笔记库本身。
