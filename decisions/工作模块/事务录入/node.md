# 03 事务录入

**父模块**：`../root.md`

## 为什么存在

把用户说的事变成事务，减少手动录入。

## 输入 / 输出

- 输入：语音/文字事务；
- 输出：结构化事务，写入事务系统。

## 边界

- 不执行长任务；
- 写入由用户审核；
- 具体字段/格式由子节点决定。

## 阶段 2 实现（2026-10-25）

- 捕获：`src/skills/tasks.py`，写入 `具体安排工作区/jarvis-inbox.md`；
- 格式：`- [ ] <事务>（捕获 <时间>）`；
- 先捕获、不自动归档；用户审核后整理到正式事务表；
- 测试：“记事务：明天下午三点买牛奶”写入成功。
