## 3. 关键决策（别丢）

| 决策 | 位置 | 一句话 |
|---|---|---|
| **插件形态开放** | `插件模块/插件规范/README.md` 5.2 | in-process / worker / 子进程 / 远程，按 isolation 分级 |
| **worker 降级为可选** | 同上 | 不是 AI 插件默认隔离层，按需实现 |
| **同步 ctx 只适用于 in-process** | 同上 | 跨进程用异步 RPC，是形态选择的代价 |
| **AI 插件风险控制** | `插件规范/AI插件风险控制.md` | 生成时约束 / 加载前 worker 测试 / 运行时监控 / 事后回滚 |
| **死循环处理** | `插件规范/死循环处理.md` | 透明化 + 警告 + 前台 + 修复插件（watchdog 独立进程） |
| **native 模块约束** | `插件规范/README.md` 5.1 | 插件不直接 import native，依赖服务接口 |
| **隔离机制全景** | `插件规范/README.md` 5 | fiber / isolate / scope / sandbox / worker / loadCache |
| **P7 无版本门槛** | `核心战略.md` | 插件不做版本验证，有功能就能接 |
| **DSH 对照结论** | `热更新/README.md` | DSH 用安装审批替代运行时隔离；我们 AI 写插件无审批，需自动化验证 |
