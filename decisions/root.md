# 贾维斯 · 根

**父模块**：无
**状态**：root 草案，待人类确认

## 问题

现有 AI 交互主要在屏幕/键盘；事务、查询、系统操作需要手动输入；缺少一个常驻、低摩擦、能调用工具的个人助理入口。

## 目标

做一个自己的贾维斯：语音/按键入口 → ASR → 对话/工具调用 → TTS；先做最小闭环，再扩展到事务、查询、系统控制；本地优先、隐私可控、高风险操作确认。

## 边界

- 不做全天录音；只在唤醒/按键时录音；
- 不静默执行高风险操作；
- 不替代人类判断；
- P0 不做唤醒词/全屋智能/多模态；
- 先做个人入口，不做通用产品。

## 验证

- P0：按键说话 → ASR → pi → TTS，延迟可接受、识别率可用；
- P1：语音创建事务草稿，用户确认后写入；
- P2：唤醒词可用，误唤醒可接受；
- 用户实际使用频率上升、纠正次数下降。

## 待人类确认

- 根目标是否就是“语音入口 + 事务/查询/工具”，还是包含更多（系统控制/主动提醒）？
- 边界是否同意（不做全天录音、不静默执行、P0 不做唤醒词）？
- 验证标准是否同意（延迟/识别率/使用频率）？
