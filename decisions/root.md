# 维叶莎 · 根

**父模块**：无

> **状态（2026-10-25）**：手机 APP 方案废弃，改为桌面软件、作为 dshiunx 插件组；本项目移交 `01a159e5`。
> **结构（2026-10-25）**：第一级只有三个模块——语音 / 工作 / 渲染。

## 问题

手动更新笔记库、录入事务、在电脑上执行操作需要大量键盘和切换；缺少一个理解笔记库、能按指令分配任务、能控制电脑、能统筹多个对话的助手。

## 目标

做一个**效率型电脑控制助手（秘书 → 统筹对话）**：

- **语音**：说话 → 文字 → 回复语音（复用 wetype ASR + Edge-TTS）；
- **工作**：读写笔记库、录入事务、按指令分配任务（拉起/继续 pi 对话）、系统控制、长期记忆、审核追溯；
- **渲染**：完整 UI——对话、结果、任务状态、键盘 + 语音输入（光听不够，要能判断汇报是否正确）；
- **不执行长任务**（交给专门 pi 对话）；
- **本地优先，隐私可控**。

## 边界

- 不做全屋控制 / 智能家居；
- 不执行长任务；
- 系统操作不二次确认（用户是技术人员），但要有记录；
- 笔记写入任意，用户自行审核；
- 不做全天录音；P0 不做唤醒词；
- 不替用户决定任务分配（按明确指令）。

## 验证

- 语音读写笔记/录入事务，手动成本明显下降；
- 按指令正确拉起/继续 pi 对话，并能在 UI 里看到状态与结果；
- 系统控制可用；
- 笔记写入可追溯/可回滚；
- 键盘输入完整可用（不是只做语音）。
