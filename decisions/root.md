# 贾维斯 · 根

**父模块**：无
**状态**：root v4，待人类确认第一层

## 问题

手动更新笔记库、录入事务、在电脑上执行操作需要大量键盘和切换；缺少一个理解笔记库、能按指令分配任务、能控制电脑的语音秘书。

## 目标

做一个**效率型电脑控制助手（秘书）**：

- 理解笔记库：可读、可写；写入任意笔记，用户自行审核；
- 录入各种事务；
- 按用户指令分配任务：需要时拉起专门的 pi 对话处理；怎么分配，具体情况具体分析；
- **不执行长任务**；
- 包含系统控制：打开应用/文件、执行命令等；
- 语音/按键入口，本地优先，隐私可控。

## 边界

- 不做全屋控制/智能家居；
- 不执行长任务（长任务交给专门 pi 对话）；
- 系统操作不做二次确认：用户是技术人员，知道自己在做什么；助手按指令执行；
- 笔记库写入任意，用户自行审核；
- 不做全天录音；只在唤醒/按键时录音；
- P0 不做唤醒词；
- 不替代人类判断；任务分配由用户明确指令触发，不自动替用户决定。

## 验证

- 语音读写笔记/录入事务，手动成本明显下降；
- 按指令正确拉起对应 pi 对话；
- 系统控制可用（打开应用/文件/命令）；
- 笔记写入可追溯/可回滚；
- 用户纠正次数下降。

## 第一层候选（按“要实现根，必须做什么”）

1. **语音入口**：说话 → 文字 → 回复语音；
2. **笔记库读写**：找到/理解/修改任意笔记；
3. **事务录入**：话 → 结构化事务 → 写入事务系统；
4. **任务分配**：按指令拉起/继续专门的 pi 对话；
5. **系统控制**：打开应用/文件、执行命令；
6. **审核与记忆**（横切）：笔记写入可追溯/回滚；助手知道当前项目/笔记/对话上下文。

这些不是分类，是实现依赖：没有语音入口无法交互；没有笔记读写无法减少更新成本；没有任务分配无法把长任务交出去；没有系统控制无法控制电脑。
