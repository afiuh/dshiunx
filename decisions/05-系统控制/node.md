# 05 系统控制

**父模块**：`../root.md`

## 为什么存在

控制电脑：打开应用/文件、执行命令。

## 输入 / 输出

- 输入：用户指令；
- 输出：应用/文件/命令执行结果。

## 边界

- 不做全屋控制；
- 系统操作不做二次确认；用户负责；
- 具体支持范围由子节点决定。

## 阶段 4 实现（2026-10-25）

- `src/skills/system.py`：`hyprctl dispatch exec` 打开应用；`subprocess` 执行命令；
- 路由：“系统：打开 …”“系统：执行 …”；
- 测试：“系统：执行 echo hi” → hi；
- 窗口/媒体/音量/截图后续接现有技能。
