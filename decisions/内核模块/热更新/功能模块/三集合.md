# 三集合

**父级**：[热更新](../热更新.md)

## 要做什么

把变更文件分成“要重载 / 不重载 / 全量重启”三类。

## 准备怎么实现

- **三个集合**（stashed / accepted / declined）：职责单一，便于调试
- **externals 判断**：入口的静态依赖树 → 全量重启

## 参考什么

- 源码：`packages/cordis-plugin-hmr/src/index.ts` 的 `stashed` / `accepted` / `declined`
- DSH：`cordis-plugin-hmr` 原版

## 决策

| 集合 | 含义 |
|---|---|
| `stashed` | 变更文件 |
| `accepted` | 需要重载的模块（变更文件 + 依赖它的模块） |
| `declined` | 不重载（externals + 没有 accepted 依赖者的模块） |

1. `accepted` = 变更文件 + 依赖它的模块（沿依赖图向上）
2. `declined` = externals + 没有 accepted 依赖者的模块
3. externals 变更 → `loader.exit()` 全量重启
