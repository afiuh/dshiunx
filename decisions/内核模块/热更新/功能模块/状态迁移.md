# 状态迁移

**父级**：[热更新](./热更新.md)

## 要做什么

reload 后保留插件状态（会话/连接/计时器不丢）。

## 准备怎么实现

- **`serialize` / `restore` 协议**（不选保留模块变量）：模块重载会清变量，必须显式迁移
- **失败只 warn**：不阻断重载（状态可丢，重载优先）

## 参考什么

- 源码：`packages/cordis-plugin-hmr/src/index.ts` 的 `serialize` / `restore`
- 插件规范：`插件规范/README.md` 第 4 条（状态外置）

## 决策

1. reload 时旧 plugin 的 `serialize()` → 新 plugin 的 `restore(state)`
2. 失败只 warn，不阻断重载
3. 插件需要跨 reload 保留的状态放 storage / session，不放模块级变量（插件规范第 4 条）
