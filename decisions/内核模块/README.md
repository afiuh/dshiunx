# 内核模块

**父级**：[核心战略](../核心战略.md)

## 这个模块负责什么

把内核做干净、做小、做稳：只保留不可插件化的机制，让上层的一切都能被插件替换。

## 这一级拆成哪几个子模块

| 子模块 | 负责什么 |
|---|---|
| [依赖注入与生命周期](./依赖注入与生命周期/README.md) | Context / Fiber / Effect / Service / Registry：服务怎么注册、怎么查找、怎么随生命周期创建和销毁 |
| [事件系统](./事件系统/README.md) | waterfall / parallel / serial / bail：插件之间怎么通信 |
| [插件加载](./插件加载/README.md) | loader：配置树怎么读、模块怎么 import、插件怎么实例化 |
| [嵌套与隔离](./嵌套与隔离/README.md) | group / isolate / scope：插件怎么套插件、服务怎么隔离、子 scope 怎么继承 root |
| [热更新](./热更新/README.md) | HMR：文件变更怎么检测、依赖图怎么分析、模块怎么替换、状态怎么保留 |

## 这一级不回答的问题

- 每个子模块内部怎么实现 → 子模块自己的 `README.md`
- 插件有哪些类别、怎么装配 → [插件模块](../插件模块/README.md)

## 硬约束

- 内核不知道任何具体插件的存在
- 删掉任意插件，内核仍能启动
- 内核不得依赖产品假设（账户、遥测、市场、客户端）
- 内核准入判据见[核心战略 P1](../核心战略.md)
