# 配置验证

**父级**：[插件加载](../插件加载.md)

## 要做什么

插件配置的 schema 验证 + 默认值补齐 + 报错。

## 参考什么

- 源码：`packages/cordis/src/fiber.ts:50`（`resolveConfig`，从 `@deepseek-ai/cordis` 导入）

## 宏观想法

插件导出 Config（Standard Schema），loader 在 apply 前验证 + 补默认值。

```
Config schema → resolveConfig → 失败抛 ValidationError
```

## 决策

1. **Config schema 验证**：插件导出 `Config`（Standard Schema），loader 在 `apply` 前调用 `resolveConfig`（`cordis/src/fiber.ts:50`）验证
2. 未提供字段用 schema 默认值补齐
3. 失败抛 `ValidationError`，fiber 进入 `FAILED`
4. **明确报错**：`ValidationError: invalid config: ...`；宿主启动器打印错误并以非零状态退出
