# 模块导入

**父级**：[插件加载](../插件加载.md)

## 要做什么

模块说明符 → ESM 模块，归一导出形状。

## 参考什么

- 源码：`packages/cordis-plugin-loader/src/index.ts:204`（`importModule`）、`:230`（`unwrapExports`）

## 决策

1. **`EntryTree.import(name)`**（`config/tree.ts:113`）：模块说明符 → ESM 模块；`cordis:` 前缀走 `builtins`（内建插件）
2. **`unwrapExports`**：归一 ESM / CJS / default 导出形状
3. **`ctx.loader.importModule(specifier)`**：动态 import 登记到 `dynamicDeps`（HMR 追踪）
