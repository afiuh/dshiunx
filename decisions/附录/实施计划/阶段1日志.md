# 阶段 1 日志：语音唤醒闭环

**父模块**：`../node.md`

## 已完成

### jarvis-daemon

- `src/daemon.py`：
  - 状态：`armed → recording → processing → speaking → armed`；
  - 触发：`SIGUSR1`（方案 A 的按键/信号触发；不做唤醒词）；
  - 录音：`parec` 16k mono，能量阈值 + 静音截断；
  - ASR：wetype；
  - 助手：`jarvis.ask_pi`（9 个 skill）；
  - TTS：Edge-TTS 晓晓；
  - 心跳：每 10s POST detector `/heartbeat`；detector 不可达 3 次退出；
  - 状态文件：`/tmp/weiyesha-state.json`。

### detector 联调

- detector `-daemon` 指向 `python3 src/daemon.py`；
- `arm true` → daemon 启动（pid 748176）；
- `arm false` → daemon 停止（pid 0）；
- 进程/状态验证通过。

### 测试

- `--text "你是谁"` → 维叶莎正常回复；
- detector arm/disarm → 启停正常。

## 录音文件策略

- 录音在内存中（`bytearray`），不落盘；
- ASR 通过 stdin 传 PCM，不写 `.wav/.pcm`；
- TTS/截图固定路径覆盖，不堆积；
- 临时音频/截图启动/退出清理。
