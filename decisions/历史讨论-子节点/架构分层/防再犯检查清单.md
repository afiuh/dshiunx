# 防再犯检查清单（never started / waiting for）

**父战略**：[架构分层](../../历史讨论.md)

## 讨论链

1. 缺包和 scope 不可见的报错长得一样，但修法完全不同。
2. 前 8 轮都在补包（都是真缺包），直到 `web`/`sandboxPolicy` 这种宿主层明明有的服务也报 `waiting`，才排除缺包。
3. 收敛：形成按顺序的判断清单。

## 清单

1. **包存在吗？** `ls packages/dsh-X` → 不存在 = 缺包
2. **服务在宿主层注册了吗？** `grep "id: X" entries.yml` → 没有 = 缺服务
3. **宿主层有、preset 看不到？** = **scope 问题**，查 `owner`/`createScope`
4. **`bin/dshiunx.ts` 的 `?`** = `Include` entry 状态未结算，以 `verify-presets.mts` 为准

## 教训

`state=3` 不一定是真失败，先查服务是否注册（`ctx.get('X')`）。
