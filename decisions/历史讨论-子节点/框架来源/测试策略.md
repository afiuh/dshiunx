# 测试策略

**父战略**：[框架来源](../../历史讨论.md)

## 讨论链

1. 框架是 vendored 的，必须验证“论文的两个保证”真的成立。
2. 不引入 vitest，用 Node 原生 `node:test` + `tsx`，减少依赖。
3. 收敛：三个验收测试 + 一个 loader 测试。

## 决定

1. **时间可组合性**：插件卸载时 `ctx.effect` 的清理函数自动执行
2. **空间可组合性**：provider 卸载后，inject 它的 consumer 自动停用
3. **声明式加载**：loader 按配置挂载/禁用插件
4. **HMR**：替换模块并保留进程
