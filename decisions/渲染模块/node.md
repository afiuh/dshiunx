# 渲染模块

**父模块**：`../root.md`

## 为什么存在

用户要能"看见"——对话、结果、任务状态、输入区。**光听不够**，必须能详细判断汇报是否正确；键盘输入必须完整保留。

## 输入 / 输出

- 输入：工作模块的结果、会话/任务状态、语音模块的状态；
- 输出：界面（对话流、状态面板、输入区）。

## 边界

- 不承载业务（只读状态 + 转发输入）；
- 键盘输入完整保留（不是只做语音）；
- 形态可换（Shell 内 / TUI / Web），共享数据层；
- 慢慢加功能，不一次做重。

## 子节点

- `对话展示/node.md`（消息流、工具调用、结果）
- `状态面板/node.md`（会话/任务/语音状态）
- `输入区/node.md`（键盘 + 语音，可编辑）
