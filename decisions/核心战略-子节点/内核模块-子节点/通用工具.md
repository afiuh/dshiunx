# 通用工具

**父级**：[内核模块](../内核模块.md)

## 要做什么

提供内核和插件都用得上的零依赖工具（`cosmokit`）。

## 为什么要做

避免每个插件自己造轮子（数组集合运算、字符串、时间、类型判断）。

## 怎么做

### 代码事实（2026-11-07 验证）

`packages/cosmokit/src/`：

| 文件 | 内容 |
|---|---|
| `array.ts` | `contain`、`intersection`、`difference`、`union`、`deduplicate`、`remove`、`makeArray` |
| `types.ts` | 类型工具 |
| `misc.ts` | 杂项 |
| `string.ts` | 字符串工具 |
| `time.ts` | 时间工具 |
| `volatile.ts` | 易变值/引用工具 |

## 边界

- 不引入业务概念
- 不做 IO

## 如何验证自己做对了

- 插件里不需要重复实现 `isPlainObject` 之类
- `grep -h "^export function" packages/cosmokit/src/array.ts` 能看到集合运算
