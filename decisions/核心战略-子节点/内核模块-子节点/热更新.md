# 热更新

**父级**：[内核模块](../内核模块.md)

## 要做什么

插件代码变化时，替换实现但保留状态（HMR），不用重启整个进程。

## 为什么要做

自进化需要"边跑边改"：AI 改一个插件，不该把整个会话重启。

## 怎么做

### 代码事实（2026-11-07 验证）

- **是复刻**：`packages/cordis-plugin-hmr/src/`（2026-11-07 曾被 checkout 误删，已恢复）
- **当前未装配**：entries.yml 里没有 hmr 条目
- **0.2.2 不再调 `serialize`/`restore`**（旧版 0.2.1 的功能）——状态保留靠**插件自己外置**（`ctx.effect` 清理 + 服务/`ctx` 持有状态）
- HMR 只保留 `fiber.entry`（`hmr/index.ts:358-359`），插件实例重建

## 边界

- 不保证所有插件可热更（有全局状态的插件会丢状态）
- 不做版本回滚（git 管）

## 如何验证自己做对了

- 改一个插件文件，进程不重启，行为变化
- 热更后会话/上下文不丢
- `grep -c "hmr" packages/bundle-arch/entries.yml` = 0（当前未装配）
