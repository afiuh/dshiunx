# 搜索工具

**父级**：[工具](../工具.md)

## 要做什么

给模型 `glob` 和 `grep`，用内置 ripgrep 做文件发现和内容搜索。

## 为什么要做

模型不能靠猜路径；glob/grep 是"先找到再读"的基础。

### 工具定义（代码验证）

`glob`：

```ts
name: 'glob'
parameters: {
  pattern: { type: 'string', required: true },  // 无 "/" 匹配任意深度的 basename
  path: { type: 'string' },                     // 默认会话 workspace
}
output: { root, paths: string[] }
```

- 只找文件，不找目录
- 含隐藏和 ignored 文件
- 按修改时间排序
- 超过 `maxResults` 时采样或保留前 N 个，并报告完整列表保存位置

`grep`：

```ts
name: 'grep'
parameters: {
  pattern: { type: 'string', required: true },  // ripgrep 正则
  path: { type: 'string' },
  include: { type: 'string' },                  // 一个 glob 过滤器，不支持列表/否定
}
output: { matches: [{ path, lineNumber, line }] }
```

- 超过 `maxMatches` 时报告完整列表保存位置
- 有 `maxLineBytes` 限制

## 边界

- **不做语义搜索**（那是 RAG）
- **不索引**（每次现搜）
- **include 只支持一个 glob**，不支持否定

## 如何验证自己做对了

- glob 能按模式找到文件，结果按修改时间排序
- grep 能按内容找到行号，按文件分组
- 结果超限时报告完整列表路径
- `diff` DSH 与 dshiunx 的 `src` = 一致
