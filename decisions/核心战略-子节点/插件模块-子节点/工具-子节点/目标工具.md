# 目标工具

**父级**：[工具](../工具.md)

## 要做什么

给模型读写"同会话目标"（goal）：`get_goal`、`create_goal`、`update_goal`，带执行时权限检查。

## 为什么要做

目标让长任务有方向：模型能查"当前目标是什么"，避免跑偏；状态变更必须有授权（人直接下的，或目标轮次驱动的）。

### 权限模型（代码验证）

`authority.ts`：

```ts
export type GoalToolAuthority =
  | { kind: 'direct-human' }                    // 人直接下的
  | { kind: 'goal-round'; goal: GoalView }      // 目标轮次驱动

export interface GoalToolExecution {
  agent: Agent
  events: readonly SessionEvent[]
  openTurnStartSeq: SessionSeq   // 当前未闭合 turn 的起点
}
```

- 状态变更必须能解析出授权（否则抛 `GOAL_TOOL_AUTHORITY_REQUIRED`）
- 用**不可变事件切面 + open turn 起点**做检查，不复制 turn 后缀

## 边界

- 目标不跨会话
- 不做自动分解（人/模型自己拆）
- 状态变更必须有授权（不是模型想改就改）

## 如何验证自己做对了

- 设目标后，`get_goal` 能查到
- 没有授权时 `update_goal` 被拒绝（`GOAL_TOOL_AUTHORITY_REQUIRED`）
- 完成/暂停/恢复状态正确
- `diff` DSH 与 dshiunx 的 `src` = 一致
- 人看：`authority.ts` 是否只做"解析授权 → 拒绝或放行"
