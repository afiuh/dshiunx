# 重复调用提醒

**父级**：[工具](../工具.md)

## 要做什么

模型连续用相同参数调用同一个工具时，在达到阈值（默认 3、5、8 次）时注入一条提醒。

## 为什么要做

模型会陷入循环（同一 grep 反复跑）；提醒让它停下来换策略，而不是一直烧 token。

## 怎么做

### 代码事实（2026-11-07 验证）

`packages/dsh-repeat-tool-reminder/`（1 个源文件，240 行）：

- 插件名：`repeat-tool-reminder`
- 事件：`repeat-tool-reminder`（`{ kind: 'repeat-tool-reminder' } & ContextFormed`）
- 只在**连续相同**（工具名 + 完整规范化参数）时计数

### Config（代码验证）

```ts
export interface Config {
  thresholds?: number[]          // 默认 [3, 5, 8]
  include?: string[]             // 要跟踪的工具名模式；空 = 全部
  exclude?: string[]             // 透明模式（既不计数也不重置）
  argumentsPreviewChars?: number // 提醒里引用的参数上限（默认 500）
}
```

- `thresholds` 校验：空数组、非整数、小于 2、重复 → **加载时抛错**（不静默回退）
- `include` / `exclude` 是 `*` 通配谓词（不是注册表引用）；匹配不到工具也合法
- `argumentsPreviewChars` 只限制**提醒里引用的参数**，检测始终用完整规范化字符串

### 行为（代码验证）

- 计数链：连续相同调用 → 计数 +1
- 达到阈值 → 注入提醒（advisory，不改结果）
- 不同参数 / 不同工具 → 重置链
- `exclude` 里的工具对链透明（不计数、不重置）

### 与 DSH 的差异（代码验证）

`diff`：**源文件一致**（DSH `packages/guard/repeat-tool-reminder/src`）。

### 装配（entries.yml）

```yaml
- id: repeat-tool-reminder
  name: '@deepseek-ai/dsh-repeat-tool-reminder'
  config:
    thresholds: [3, 5, 8]
```

## 边界

- **只提醒，不阻止**
- **不做跨会话检测**
- **参数预览有上限**（避免大 payload 进提醒）

## 如何验证自己做对了

- 连续 3 次相同调用，出现提醒
- 不同参数不触发
- `thresholds: [1]` 或 `[2,2]` 启动报错
- `diff` DSH 与 dshiunx 的 `src` = 一致
- 人看：检测是否用完整规范化参数（不是截断后的预览）
