# 上下文管理

**父级**：[插件模块](../插件模块.md)

## 要做什么

管理模型的上下文预算：计量 token、压缩历史、卸载图片、修剪工具结果、spill 大输出。

## 为什么要做

上下文窗口是智能体寿命的天花板。不管理上下文，跑几天就爆；管理得好，可以跑很久。

> 用户（2026-10-22）：
> "上下文管理：token-meter、compaction-basic、tool-result-pruner。"

## 怎么做

### 代码事实（2026-11-07 验证）

| 包 | 职责 | 源码 |
|---|---|---|
| `dsh-token-meter` | 回放感知的 token 计量 | `src/`（11 个文件：estimate、projection、surface-projection、surface-fold、breakdown-projection、usage-projection、turn-usage、route-pricing、client、types、index） |
| `dsh-compaction-basic` | 阈值触发压缩 + LLM 摘要 | `src/`（5 个文件：config〔`thresholdRatio`、`retention`、`compactionRetries`〕、summarizer、region、types、index） |
| `dsh-compaction-tool-result-pruner` | 工具结果 head/middle/tail 修剪（无模型） | `src/config.ts`、`index.ts` |
| `dsh-compaction-image-offload` | 图片超预算替换为占位符 | — |
| `dsh-spill-policy` | token 预算内保留 + 可恢复路径 | `src/`（4 个文件：retention、notice、types、index） |
| `dsh-spill-local` | 本地 spill 存储 | — |

### 触发顺序

```
token-meter 超阈值（thresholdRatio）
  → compaction-basic（摘要，最多 compactionRetries 次）
  → 如果还超：tool-result-pruner（修剪 head/middle/tail）
  → 如果还超：image-offload（图片 → 占位符）
  → spill（大输出落盘，只留 attachment path）
```

### 关键配置（代码验证）

| 配置 | 位置 | 含义 |
|---|---|---|
| `thresholdRatio` | `compaction-basic/config.ts` | 触发压缩的 token 比例 |
| `retention` | `compaction-basic/config.ts` | 保留比例（与 threshold 一起校验） |
| `compactionRetries` | `compaction-basic/config.ts` | 压缩重试次数 |
| `budget` | `spill-policy/index.ts` | 保留结果的最大 token（含图片描述和省略提示） |

### DSH 0.2.2 的变更（决策依据）

| 变更 | 决策含义 |
|---|---|
| `projection-snapshot-scope`：snapshot 只计算返回的单元 | 大会话的 snapshot 读取变快——token-meter 的 breakdown 可能受影响 |
| `projection-released-checkpoint`：checkpoint 保留已释放单元最后一行 | 检查点不再省略最后一行，恢复时少一次重放 |
| `pi-ai-request-image-count`：图片超 50 张省略最老的 | 图片 offload 多一个**数量**维度（当前只有 token 预算维度） |

**dshiunx 的决策**：
- snapshot scope：**建议跟**（性能）
- checkpoint：**建议跟**（恢复正确性）
- 图片数量维度：**建议跟**（与 token 预算互补）

## 边界

- **压缩不丢事件**：原始事件在 session 里，压缩只影响"发给模型的内容"
- **修剪不做语义判断**：head/middle/tail 是机械的
- **spill 可恢复**：落盘的内容能按 attachment path 读回
- **图片卸载不删图**：只替换为占位符 + 路径

## 如何验证自己做对了

- 长会话跑到阈值，能看到压缩事件，模型请求变小
- 压缩后仍能回答"前面说过什么"（靠摘要/投影）
- 图片超限时请求不失败
- spill 后模型能按路径读回
- `grep -n "thresholdRatio\|compactionRetries" packages/dsh-compaction-basic/src/config.ts` 能看到配置项
- 人看：压缩后模型请求的 token 数是否显著下降
