# 对话管理

**父级**：[具体插件](../具体插件.md)

> **同级插件**：不属于维叶莎（维叶莎只是使用者之一）。

## 为什么存在

对话散落在各插件（web / voice / dispatch），需要统一记录 ID、按插件分组，给"统筹对话"提供数据。

## 接口（`ctx.conversations`）

| 方法 | 作用 |
|---|---|
| `register({ id, group, createdAt, title? })` | 登记对话（重复 id 覆盖） |
| `setCurrent(group, id)` | 设某组当前会话 |
| `current(group)` | 某组当前会话 id |
| `list(group?)` | 列表（新的在前） |
| `groups()` | 按组归并（UI 用） |
| `remove(id)` | 删除记录 |

## 存储

`~/.local/share/jarvis/sessions.json`：

```json
{ "entries": [{ "id": "...", "group": "jarvis-web", "createdAt": 0, "title": "Web 对话" }],
  "current": { "jarvis-web": "..." } }
```

## 分组

按**插件**分组：`jarvis-web` / `jarvis-voice` / `jarvis-dispatch` …——哪个插件引出的对话，归哪一组。

## 边界

- 只管"索引"，不存对话内容（内容在 dshiunx session）
- 同级插件（不属于维叶莎）
- 只有用户能开新对话（插件提供入口，前端不自动创建）
