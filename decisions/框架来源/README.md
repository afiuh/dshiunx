# 框架来源

**战略**：直接 vendor 上游框架，不从零实现。

## 讨论链

1. 起点：用户提出“根据源码和技术论文，把框架搭起来（抄/微调），再慢慢添东西”。
2. 关键判断：DSH 的源码是经过技术测试的产品，从零实现语义易错、周期长。
3. 收敛：复制上游框架（MIT），在它之上做特化。

## 用户原话

> “这个DSH的理念是一切皆插件,智能体本身也只是一个插件而已，它的核心是那个框架”
> “他的源码已经是经过技术测试过的产品了，不然也不会开源出来。我们是直接借鉴一个成熟产品，不是从零开始造的”

## 决定

复制 `cordis`、`loader`、`include`、`group`、`hmr`、`schemastery`、`cosmokit` 到 `packages/`。
