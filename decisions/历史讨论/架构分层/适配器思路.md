# 适配器思路（记录，暂不实施）

**父战略**：[架构分层](../历史讨论.md)

## 讨论链

1. 用户问：能不能像 DSH 适配 Claude mods 一样，让 Claude 插件在 dshiunx 里跑。
2. 调研：DSH 的 Claude mods 适配是 **API 桥接**（声明式钩子），不是运行 Claude 运行时。
3. 判断：“让插件以为在 Node 上”最务实的方式是真的给一个 Node 进程，而不是模拟 Node API。
4. 收敛：分级方案——声明式插件用轻量引擎 + 有限 shim；原生 Node 插件跑 Node 子进程。

## 决定

记录为未来架构选项，第一版不实施。
