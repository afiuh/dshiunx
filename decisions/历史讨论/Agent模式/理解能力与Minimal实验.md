# 理解能力瓶颈与 Minimal 实验

**父战略**：[Agent模式](../历史讨论.md)

## 讨论链

1. 用户指出“当前关键瓶颈是 AI 的理解能力”，并提炼出五种不理解：语义降维、分不清层级、用展开代替判断、不敢否定旧概念、不检查前提。
2. 关键区分：**理解能力**由模型权重决定，模式改不了；**理解表现**由上下文/提示决定，模式能改。
3. Minimal 去掉的是“干扰”（工具指导/运行时上下文），不是“理解”；项目指令/协作契约是支撑，不是干扰。
4. 收敛：设计 A/B/C 三组实验，验证“极简 + 懂你”。

## 实验计划

| 组 | 配置 | 测什么 |
|---|---|---|
| A | 纯 Minimal | 基线 |
| B | Minimal + 协作契约 | 极简 + 懂你 |
| C | Standard | 当前基线 |

指标：成功率、轮次、token、人工评分。

## 预期

B 可能最好——保留“少干扰”，补上“懂你”。
