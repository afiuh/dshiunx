# 四模式分析

**父战略**：[Agent模式](../../历史讨论.md)

## 讨论链

1. 起点：用户调查 DSH 四种模式（Standard / PTC / Minimal / Creator）的现状与 Minimal 争议。
2. 对照 preset 定义与用户项目画像（长会话、多阶段、用户主导设计、多工具链）。
3. 收敛：Standard 是主力；PTC 适合批量数据；Creator 适合改造；Minimal 不适合日常长任务。

## 模式定义

- **Standard**：完整工具集 + 完整引导
- **PTC**：Standard + `run_code` / `workflow-ptc` / `tool-workflow`
- **Minimal**：`persona.complete: true` + `includeRuntimeContext: false`，工具只有 bash + readImage + compaction
- **Creator**：Standard + `tool-cordis` + `plugin-manager` + 开发技能
