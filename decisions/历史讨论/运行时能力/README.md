# 运行时能力

**战略**：在 vendored 框架之上，按“特化版”原则裁剪运行时能力。

## 讨论链

1. 框架复制后，第一版要决定装哪些插件、砍哪些。
2. 判断：特化版 = 保留运行时必需，去掉平台/产品化能力。
3. 收敛：沙箱后置、无审批、项目指令参考 DSH、外围简化。
