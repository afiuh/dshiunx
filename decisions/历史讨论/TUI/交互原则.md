# 交互原则：不打扰 + 对话回滚/修改

**父战略**：[TUI](../README.md)

## 讨论链

1. 主要参考 pi 的“不打扰用户”。
2. 其他参考 `dsh-TUI`：对话回滚、直接修改对话。
3. 收敛：不打扰 + 回滚 + git 管理。

## 不打扰原则

- 默认不弹审批（审批由插件提供，需要时再装）
- 不自动弹窗/通知
- 不打断流式输出
- 状态栏不刷屏
- 工具调用折叠，不默认展开
- 错误只显示一行，不刷整屏

## 回滚/修改对话

- double-Esc time rewind：截断到某个 seq
- 直接修改对话：替换历史消息后重放
- 实现基础：`session/event` 是 append-only log，回滚 = 截断，修改 = 替换 + 重放

## git 管理

每做一个小功能就 commit，方便回滚。
