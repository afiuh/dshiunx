# 01 语音入口

**父模块**：`../root.md`

## 为什么存在

没有声音，助手无法交互。

## 输入 / 输出

- 输入：用户语音（复用 fcitx5-vinput 出字）/按键；
- 输出：文字（给后续节点）或 TTS 语音回复。

## 边界

- 不做全天录音；
- 不做本地 ASR：复用 fcitx5-vinput（线上、自动纠错/降噪、不占显存）；
- P0 先按键说话；
- TTS 默认：Edge-TTS `zh-CN-XiaoxiaoNeural`（晓晓，女，免费/不占显存）；
- 唤醒词由本节点子节点决定。
