# 01-01 输入法接入

**父模块**：`../node.md`

## 为什么存在

语音输入复用 fcitx5-vinput；必须把“出字”变成助手可用的文本。

## 输入 / 输出

- 输入：fcitx5-vinput 出字（Alt+Z 说话）；
- 输出：文本（给助手/pi）。

## 边界

- 不做本地 ASR；
- 不截获隐私/不常驻监听键盘；
- 不干扰输入法正常使用。

## 待确认

- 取文本方式：剪贴板、输入框、活动窗口，还是输入法协议？
- 触发方式：Alt+Z 后自动取，还是助手主动唤起输入法？

## 验证

说一句话，助手能拿到正确文本；不干扰正常输入。
