# jarvis-notes（笔记库）

## 何时用

用户要查笔记、读笔记、写/更新笔记、找资料、改某个笔记。

## 笔记库位置

`/home/ufuish/obsidian-笔记`

- 一级文件夹 = 问题系统；每个文件夹有 `根声明.md`；
- `index.md` = 首页投影/入口；
- 文件树 + 双链引用；改动前查引用，改名/移动查全库；
- `草稿集/` = 孵化区；`工具的使用/` = 工具手册 + 项目台账；`我的历史/` = 归档。

## 搜索

- 用 `rg -l --glob '*.md' -i <关键词> /home/ufuish/obsidian-笔记`；
- 返回相对路径 + 命中行；
- 先搜再读，不凭记忆猜路径。

## 读取

- 按相对路径读取；路径必须落在笔记库内；
- 大文件分段读；不要一次塞满上下文。

## 写入

- 默认写入 `草稿集/AI草稿/jarvis-inbox.md`；
- 用户指定路径时，路径必须落在笔记库内；
- 写入前备份（`~/.local/share/jarvis/backups/`）；
- 写入后记录 audit（谁/何时/什么/结果）；
- 不静默覆盖；覆盖前确认；
- 写入内容要可追溯。

## 改名/移动

- 先 `rg` 查文件名、双链 `[[...]]`、引用路径；
- 同步更新引用方；
- 分步 git commit（前缀 `arch-obsidian:`）；
- 不物理移动系统目录（`/usr`、`/etc`、`/var`、`/boot`、`/opt`）。

## 维护

- 用户驱动：用户点题才维护；不自动批量重构；
- 变更后过《维护更新检查手册》（变更类型 → 检查清单）；
- 索引规则见《使用手册》：标题层级 = 文件夹层级；每个标题下带位置链接；
- 敏感文件红线：`~/.git-credentials`、`~/.dev-sidecar/*.key.pem`、`/etc/shadow` 不读不写；
- 引用用户原话一字不改。

## 边界

- 不替用户决定笔记结构/分类；
- 不批量删改；
- 不把草稿当正式笔记；
- 写入失败/路径越界就停，报告。
