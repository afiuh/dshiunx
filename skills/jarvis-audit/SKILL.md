# jarvis-audit（审核/追溯）

## 原则

- 默认做法，不是死板流程；具体情境具体分析。
- 不确定就查：`~/.local/share/jarvis/audit.jsonl`、`backups/`、git log、相关文件；查不到就问用户。
- 审计是事实记录；不删、不改、不美化。

## 何时用

写入/修改笔记、事务、系统操作；用户问“改了什么/怎么恢复”。

## 记录

- `~/.local/share/jarvis/audit.jsonl`：时间、类型、对象、动作、结果；
- 写入前备份到 `backups/`；
- 系统操作记录命令/结果/退出码；
- 失败也记录。

## 回滚

- 先查 audit/备份，确认要恢复到哪个版本；
- 回滚前备份当前状态；
- 回滚后记录；
- 不确定就问用户。

## 边界

- 不替代用户审核；
- 不删除审计记录；
- 不静默改历史；
- 不泄露审计中的敏感信息。
