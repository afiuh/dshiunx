# jarvis-screen（屏幕/视觉）

## 原则

- 默认做法，不是死板流程；具体情境具体分析。
- 不确定就查：`grim --help`、`slurp --help`、系统配置档案、Hyprland 配置；查不到/涉及隐私就问用户。
- 规则冲突时，以本机现状/用户指令为准。

## 何时用

用户说“看屏幕/截图/这个窗口/屏幕上是什么/这张图”。

## 截图

- 全屏：`grim /tmp/jarvis-screen.png`；
- 区域：`grim -g "$(slurp)" /tmp/jarvis-screen.png`；
- 先全屏，需要细节再区域；
- 截图后交给 pi 的 `read` 读取图片，再回答。

## 边界

- 按需截图；不常驻截屏、不后台录屏；
- 不截敏感内容（密码、密钥、私密聊天）除非用户明确要求；
- 截图临时文件可清理；
- 不确定画面是否包含隐私 → 先问。

## 验证

- 截图文件存在且可读；
- 回答与画面一致；看不清就说看不清，不编。
