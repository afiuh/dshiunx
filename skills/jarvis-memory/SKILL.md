# jarvis-memory（长期记忆）

## 原则

- 默认做法，不是死板流程；具体情境具体分析。
- 不确定就查：`~/.local/share/jarvis/memory.db`、归档 `archives/INDEX.md`、活跃项目台账、项目文档；查不到就问用户。
- 记忆是线索，不是事实；以笔记/台账/项目文档为准。

## 何时用

用户问“之前…/上次…/你记得…”，或当前任务需要跨会话背景。

## 记什么

- 项目状态、偏好、重要决策、事务；
- 不记隐私、token、密码、一次性闲聊；
- 记录时写清时间/来源/上下文。

## 检索

- 先查 SQLite `events`（关键词/最近）；
- 需要细节 → 归档 L0 → L1 → L2；
- 只注入必要片段，不污染上下文；
- 找不到就说没有，不编。

## 更新/遗忘

- 过时信息标记/删除；
- 重要记忆可回滚；
- 用户要求遗忘 → 执行并记录。

## 边界

- 不主动翻旧账；
- 不把记忆当事实；
- 不泄露隐私；
- 不无限膨胀：定期清理。
