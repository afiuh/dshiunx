# jarvis-dispatch（任务分配）

## 何时用

用户提出长任务、编程、完整项目、多步实现，或明确说“交给某个对话”。

## 台账

`/home/ufuish/obsidian-笔记/工具的使用/活跃项目台账.md`

- 每个项目有负责对话 ID、启动命令、项目文档、状态；
- 启动：`pi --session <ID前缀>`；
- 项目完成后台账移除，内容交归档。

## 分配

1. 判断任务类型：短问答/当前对话；长任务/编程/多步 → 分配。
2. 从台账找最匹配的负责对话。
3. 用 `pi --session <ID> -p "<任务>"` 拉起/继续。
4. 结果回传用户；长任务可后台，不阻塞当前对话。
5. 没有匹配对话 → 问用户：新建对话还是指定一个。

## 边界

- 不自己执行长任务；
- 不替用户决定分配；
- 不拉起无关对话；
- 不泄露 token/隐私；
- 项目完成后提醒更新台账/归档。
